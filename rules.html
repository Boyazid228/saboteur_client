🎯 Goal of the Game

You are a dwarf digging through tunnels to find gold. But not everyone is on the same side—some players are gold miners, while others are secret saboteurs.

Gold miners try to reach the hidden treasure.
Saboteurs try to block the way.

After 3 rounds, the player with the most gold nuggets wins!

🧩 Game Setup

Choose roles based on number of players:

  • 3 players: 1 saboteur, 3 gold miners
  • 4 players: 1 saboteur, 4 gold miners
  • 5 players: 2 saboteurs, 4 gold miners
Shuffle and deal 1 dwarf role card to each player. Keep it secret.

Set up:
  • 1 Start Card (ladder, face up)
  • 3 Goal Cards (1 gold, 2 rocks – face down)
  • Place them in a line with space in between to build the path.
  • Separate and shuffle the Path Cards, Action Cards, and Gold Nugget Cards into different decks.

🔄 How to Play

Each turn, a player:

  • Plays one card:
    • Place a Path Card to build the tunnel
    • Use an Action Card (to help or block others)
    • Or Pass (discard 1 card face down)
  • Draws 1 card from the deck
If the deck is empty, skip the draw step.

🛤 Playing Path Cards

Build a tunnel from the Start Card toward one of the Goal Cards.
Paths must connect properly.
Every new card must link back to the Start Card.

Gold miners want to build a clear path to the treasure.
Saboteurs secretly try to stop them.

🛠 Playing Action Cards

  • Broken Tool: Place in front of a player to block them from playing path cards.
  • Fix Tool: Repair a broken tool. Must match the tool type.
  • Rockfall: Remove any path card from the maze (except Start/Goal).
  • Map: Secretly look at one Goal Card.
  • Only one of each broken tool type can be in front of a player at once.

🚫 Passing a Turn

If you can’t or don’t want to play a card, discard one face down.
If you have no cards left, just skip your turn.

🏁 End of Round

A round ends if:

  • A path reaches the gold treasure (Goal Card is flipped to confirm), or
  • The deck is empty and no one can play.
All roles are revealed. Then, hand out gold nuggets:
  • If miners won: The player who reached the treasure takes gold cards equal to the number of gold miners, keeps 1, and passes the rest counter-clockwise to other miners.
  • If saboteurs won:
    • 1 saboteur = 4 nuggets total
    • 2 saboteurs = 3 nuggets each
  • Note: If there’s no saboteur in the round and miners fail, no one wins gold.

🔁 New Round

Reset the Start and Goal cards.
Shuffle and deal dwarf roles again (include the set-aside card).
Shuffle all other cards and deal starting hands.
The next round starts with the player to the left of the last one who played a path card.

🏆 End of the Game

After 3 rounds, everyone counts their gold nuggets.
The player with the most nuggets wins! If tied, they share the victory.
